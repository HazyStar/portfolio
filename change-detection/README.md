# Change Detection — 脱敏案例

> **类型**：计算机视觉 / 遥感或影像变化检测（私人仓库 / 研究相关）  
> **方向**：PyTorch · 语义分割 / 变化检测  
> **仓库状态**：源代码与未发表方法细节不公开

---

## 1. 背景与本人职责

双时相影像变化检测用于识别地表/场景随时间发生的变化，常见于遥感监测、巡检与科研实验。

本人职责侧重：

- 数据管线：样本组织、增强、训练/验证划分  
- 模型训练与评测：基线对比、指标分析  
- 推理与可视化：结果图、误差案例分析  

## 2. 技术栈（公开口径）

- Python、PyTorch  
- 语义分割 / 变化检测常用骨干与解码结构  
- 训练脚本、评测脚本、可视化工具  
- 公开或授权数据集上的实验（具体数据授权范围不在此展开）  

## 3. 脱敏流程

```text
[ 双时相输入 ] → [ 预处理 / 配准约束 ]
        → [ 变化检测模型 ]
        → [ 后处理 ]
        → [ 指标评测 + 可视化 ]
```

## 4. 关键技术难点

- **类别不平衡**：变化像素通常远少于未变化区域 → 损失与采样策略需针对性设计  
- **伪变化**：光照、季节、配准误差易造成误检 → 需结合后处理与错误案例分析  
- **可复现实验**：固定划分、记录超参与随机种子，保证对比公平  

## 5. 成果（公开可说）

- 完成可训练、可评测、可可视化的实验闭环  
- 能就指标（如 IoU / F1 等）解释模型行为与失败模式  
- 相关未发表方法与单位知识产权内容不在公开仓库披露

```text
源代码与未发表研究方法因知识产权要求不公开。
```
